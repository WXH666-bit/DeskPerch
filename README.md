# DeskPerch

[中文](README.md) | [English](README.en.md)

<img src="assets/deskperch.png" width="88" alt="DeskPerch Logo">

一个安静、轻量的 Windows 桌面外设状态挂件。使用 C++20、原生 Win32 和 GDI+，无需安装、登录、管理员权限或额外运行时。

[下载最新版本](https://github.com/WXH666-bit/DeskPerch/releases/latest) · [Actions 构建](https://github.com/WXH666-bit/DeskPerch/actions) · [设备支持与限制](docs/SUPPORT.md) · [本轮验证记录](docs/VALIDATION.md)

## 功能

- 完整模式：逐台展示外接鼠标的电量与真实 DPI，以及外接键盘、屏幕和 USB 接口状态。
- 简约模式：每只鼠标一行电量与 DPI，多鼠标显示名称；容器随内容收缩，长列表支持滚轮与窄滚动条。
- 挂接 Explorer 桌面图标视图，普通应用可遮挡挂件；无任务栏按钮、Alt+Tab 项或主动抢焦点。
- 仅关注外设，排除可确认的内置键盘、触摸板、内置面板和内部 USB 接口。
- 透明／浅白背景，首次默认浅白，之后恢复用户选择；深灰文字、加粗数值和适配背景的浅色衬边。
- 托盘集中管理背景、显示模式、位置锁定、关注对象、可见性、自启动和退出。
- 记住位置和设置，支持多屏位置恢复，同一用户会话只运行一个实例。

没有驱动安装、硬件调校、DPI 修改、广告、遥测或联网功能。外观采用静态半透明绘制，不持续捕获壁纸，不运行实时折射或常驻动画。

## 使用

从 Releases 下载便携 ZIP，解压后双击 `DeskPerch.exe`；也可单独下载 EXE。首次显示在主屏工作区右上角。

右键系统托盘图标设置（图标可能在折叠区域）；未锁定时可直接拖动。不勾选对象时自动显示外设及已占用的外部接口，隐藏空闲端口和集线器本体。首次勾选后进入全局手动模式：只显示勾选的对象，支持跨类别多选。取消最后一个勾选，或点击“自动显示已连接设备”，恢复自动模式。手动关注的断开设备保留名称；简约模式无鼠标时显示“未关注鼠标”。“隐藏”保留托盘，“退出”结束进程。自启动默认关闭；移动 EXE 后重新关闭／开启自启动可更新路径。

目标平台：Windows 11 24H2／25H2 x64。实际验证环境为 Windows 11 25H2，其他构建、壁纸软件和多屏组合仍需验证。EXE 尚未签名。应用界面目前为中文，说明文档提供中英文。

## 数据与隐私

| 显示 | 含义 |
| --- | --- |
| 百分比／DPI | 设备实际报告且未过期的数据 |
| 未连接 | 已确认缺席；正常使用中可不连接该类外设 |
| 暂不支持 | 未发现受支持的能力 |
| 暂不可用／状态未知 | 查询失败、超时，或无法确认无线本体在线 |
| 状态已过期 | 旧值不再作为当前数据 |

不会以 0% 代替未知电量，不会用指针速度或预设代替真实 DPI。显示器启用不代表物理电源开启；USB 端口号不一定对应机箱印刷编号。

罗技 HID++ 和已实测的狼途 M8 MAX 2.4G 接收器（`A8A5:2255`，`LTM8 2.4G`）支持真实电量与当前 DPI。狼途关闭电源时接收器仍可能回复电量，程序会结合有效 DPI 回复判断，不继续显示缓存数值；无法确认状态时显示“暂不可用”。有线／蓝牙模式及其他狼途型号尚未验证。

PRO X Wireless 充电期间重新开机可能报告突然降低的百分比；检测到这种异常时显示“电量待确认”，并保留可确认的充电状态。该提示表示设备报告尚未被交叉验证，不代表电池容量发生了对应变化。

其他设备通过标准 HID Feature / 蓝牙 BAS 获取明确的电量百分比；未验证的 DPI 协议显示“暂不支持”。只有已确认的无电池有线型号显示 `-`，普通 USB 连接不等于无电池，详见支持表。

设置升级到 v3，首次从 v1/v2 升级会重置关注对象为自动模式，保留背景、位置、锁定、可见性及显示模式。之后恢复多选与离线设备名称。

设置保存在 `%LOCALAPPDATA%\DeskPerch\settings.dat`。不记录输入内容、鼠标轨迹、其他应用内容或设备状态历史。

## 构建与打包

需要 Visual Studio 2022 的 C++ 桌面开发工具、Windows SDK、CMake 3.24+ 和 PowerShell。

```powershell
.\build.ps1
.\tools\package.ps1 -Version v1.1.1
```

构建脚本运行 CTest 并输出 `out/DeskPerch.exe`，重新构建前请先退出该 EXE。打包脚本向 `dist` 输出便携 ZIP、独立 EXE 和 SHA-256 校验文件。静态链接 MSVC 运行库，只依赖 Windows 系统 DLL。

探测和采样工具仅供开发验证，不随日常进程自动启动。单元测试不等于实机桌面或 24 小时稳定性验收。本机诊断、截图、原始采样及开发过程报告不上传仓库。

